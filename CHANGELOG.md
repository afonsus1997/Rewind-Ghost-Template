# Changelog

All notable changes to the Rewind theme. Versions match `theme/package.json`.

## 1.3.2

- Multiple artists on one album display as "Artist A & Artist B".

## 1.3.1

- Standout tracks can show the album's real track numbers (`3 Track x` → **03** Track x).

## 1.3.0

- Review sidebar: **Listen** (first music embed) and **Standout tracks**, filled automatically from the post body, plus Tags.

## 1.2.0

- Reviews index page (`/reviews/`) with live filter and Newest / A–Z sorting.

## 1.1.0

- Artists, Genres and Years index pages.
- Genre chips exclude artist and year tags using filters.

## 1.0.0

- First release: homepage with welcome banner, latest-review hero and cover grid; review, artist/tag, About, page and error templates; newsletter signup; Ghost search.
