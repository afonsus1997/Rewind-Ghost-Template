## Using GitHub issues and Projects instead

1. Open a new issue › **Album to review**. Fill in the album, artist and why you want to write about it.
2. Create a GitHub **Project** (Board view) with columns: *Idea*, *Listening*, *Drafting*, *Ready*, *Published*.
3. Add issues to the board and drag them across as you go.
4. Close the issue with a link to the published review.

Labels created by the template: `review`. Add genre labels (`jazz`, `rock`…) to filter the board if you like.
